# CI/CD Deployment Guide

This document describes the Continuous Integration and Continuous Deployment (CI/CD) pipeline for the Meeting Scheduler application.

## Overview

- **CI Platform**: GitHub Actions
- **CD Platform**: Render
- **Deployment Trigger**: Automatic on every push to `main` branch
- **Database**: PostgreSQL (production), SQLite (development)
- **Static Files**: Served via WhiteNoise

## Render Deployment

### Configuration Files

#### 1. `render.yaml`
Blueprint for Render infrastructure:
- **Web Service**: Django app running on gunicorn
- **Database**: PostgreSQL (free tier)
- **Auto-deploy**: Enabled on main branch

#### 2. `build.sh`
Build script executed during deployment:
```bash
#!/usr/bin/env bash
set -o errexit

pip install --upgrade pip
pip install -r requirements.txt
python manage.py collectstatic --no-input
python manage.py migrate --no-input
python manage.py create_default_admin
```

### Environment Variables (Configure on Render)

**Required:**
- `DATABASE_URL` - Auto-configured by Render PostgreSQL
- `SECRET_KEY` - Auto-generated by Render
- `DEBUG` - Set to `False`
- `ALLOWED_HOSTS` - Set to your Render domain (e.g., `meeting-scheduler.onrender.com`)

**Optional:**
- `DJANGO_SETTINGS_MODULE` - Defaults to `meeting_scheduler.settings`

### Production Settings

The app automatically detects production environment via `DATABASE_URL`:
- **Database**: PostgreSQL (production) / SQLite (development)
- **Static Files**: Served via WhiteNoise with compression
- **HTTPS**: Forced SSL redirect in production
- **Security Headers**: HSTS, XSS protection, MIME sniffing prevention
- **Session Security**: Secure cookies, 1-hour timeout

## Deployment Steps

### Initial Setup on Render

1. **Create Render Account**
   - Sign up at https://render.com

2. **Connect GitHub Repository**
   - Dashboard → New → Blueprint
   - Connect your GitHub repository
   - Grant Render access to the repo

3. **Deploy from Blueprint**
   - Render will detect `render.yaml`
   - Review the configuration
   - Click "Apply"
   - Render will:
     - Create PostgreSQL database
     - Create web service
     - Set up environment variables
     - Run initial deployment

4. **Configure Environment Variables** (if not using Blueprint)
   - Go to Web Service → Environment
   - Add/verify:
     ```
     SECRET_KEY=<auto-generated>
     DEBUG=False
     ALLOWED_HOSTS=<your-app-name>.onrender.com
     DATABASE_URL=<auto-configured>
     ```

5. **Access Your Application**
   - URL: `https://your-app-name.onrender.com`
   - Default admin: `admin` / `admin123` (change immediately!)

### Continuous Deployment

**Automatic Deployment Workflow:**
1. Developer pushes code to `main` branch
2. GitHub Actions CI runs all tests
3. If tests pass, Render detects the push
4. Render automatically:
   - Pulls latest code
   - Runs `build.sh`
   - Restarts web service
5. Application is live with new changes

**Deployment Time:** ~3-5 minutes

### Manual Deployment
If needed, trigger manual deploy on Render:
- Dashboard → Your Service → Manual Deploy → Deploy latest commit

## Database Management

### Migrations
Migrations run automatically during deployment via `build.sh`.

**Manual Migration (if needed):**
1. Render Dashboard → Your Service → Shell
2. Run: `python manage.py migrate`

### Backup
Render PostgreSQL includes automatic backups (free tier: 7 days retention).

**Manual Backup:**
1. Render Dashboard → Database → Backups
2. Click "Create Backup"

### Access Database
```bash
# Via Render Shell
python manage.py dbshell

# Or connect directly using DATABASE_URL
# (Find in Environment Variables)
```

## Security Checklist

### Production Security (Automatically Enabled)
- ✅ `DEBUG = False`
- ✅ `SECRET_KEY` from environment variable
- ✅ `ALLOWED_HOSTS` restricted to Render domain
- ✅ HTTPS enforced (`SECURE_SSL_REDIRECT`)
- ✅ Secure cookies (`SESSION_COOKIE_SECURE`, `CSRF_COOKIE_SECURE`)
- ✅ HSTS enabled (31536000 seconds)
- ✅ WhiteNoise for static files
- ✅ PostgreSQL (not SQLite)
- ✅ Security headers (X-Frame-Options, X-Content-Type-Options)

## Troubleshooting

### Build Fails
- **Check**: `build.sh` has executable permissions
- **Check**: All dependencies in `requirements.txt`
- **Check**: No uncommitted migrations
- **Logs**: Render → Your Service → Logs

### Application Errors
- **Check**: Environment variables set correctly
- **Check**: `ALLOWED_HOSTS` includes Render domain
- **Check**: Database connection (DATABASE_URL)
- **Logs**: Render → Your Service → Logs → Filter by "error"

### Static Files Not Loading
- **Check**: `python manage.py collectstatic` ran successfully
- **Check**: WhiteNoise middleware is enabled
- **Check**: `STATIC_ROOT = BASE_DIR / 'staticfiles'`

### Database Connection Issues
- **Check**: PostgreSQL service is running (Render Dashboard)
- **Check**: `DATABASE_URL` environment variable is set
- **Check**: `psycopg2-binary` is in requirements.txt
